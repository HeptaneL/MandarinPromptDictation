# Mandarin Prompt Dictation

Chrome 扩展，可将普通话语音实时识别为中文文本，并自动翻译为英文提示。

## 功能

- 使用 Web Speech API 进行普通话语音识别。
- 自动翻译为英文，方便直接作为英文 Prompt 使用。
- 中文与英文文本各自提供一键复制按钮。

## 安装与使用

1. 打开 `chrome://extensions/` 并启用开发者模式。
2. 点击“加载已解压的扩展程序”，选择本项目目录。
3. 固定工具栏图标后，点击弹出窗口中的“开始录音”获取麦克风权限并开始语音输入。
4. 停止录音或清除文本即可重新开始。

> **注意**：英文翻译调用 `https://translate.googleapis.com` 接口，使用时请保持网络可用。
